## ✅ 已完成

### P0: 邮箱验证跳转 localhost Bug ✅

`signUp()` 和 `resetPasswordForEmail()` 新增 `redirectTo: window.location.origin`，确认/重置链接不再错误跳转到 localhost。

### P1: Toast 通知系统 + 自动刷新 ✅

- 新增 `showToast(msg, type)` 替换全部 ~71 处 `alert()` — 颜色编码（success/error/warning/info）、自动 3 秒消失、固定右上角
- 商品录入保存后自动刷新侧边栏和管理表格

### P2: 图床 API 可配置化 ✅

- 云端设置新增图床配置：API 地址、表单字段名、Token、响应 JSON 路径
- 适配 Chevereto / Lsky Pro / 通用图床三种响应格式
- Netlify CSP `connect-src` 开放 `https:` 以支持用户自选图床
- 错误提示显示具体原因（之前一律显示"上传失败"）

### P3: 关于页面 ✅

- 新增 `#about-screen`，版本号 v1.2.0、原作者秋洛、CC BY-NC-SA 4.0 许可证
- `APP_VERSION` 常量在 `core.js`，页面自动填充

### XSS 防护 ✅

- 全项目 `innerHTML` 注入点已包裹 `escapeHtml()`（`core.js`）
- README 新增安全注意事项章节

### 删除不必要的功能 ✅

- 移除废弃的副团长（assistant）模式

### 关键 Bug 修复 ✅

| Bug | 根因 | 影响 |
|-----|------|------|
| 订单无法保存/查询 | `data.js` 重复 `let` 声明 → `SyntaxError` | `saveData`/`syncToCloud` 全部未定义 |
| 全局密钥无法保存 | `saveQueryKey()` 在文件拆分时遗失 | 密钥保存按钮无效 |
| 团员门户崩溃 | `buyer-portal.js` 花括号错误 + `shipping-export.js` 重复代码 | 买家端 / 导出 JS 解析失败 |
| 图床上传被拦截 | CSP `connect-src` 只允许 Supabase | 任何图床均失败 |
| `initCloudData` 未定义 | `data.js` 在 `auth.js` 前加载 | 页面初始化偶发失败 |

## 新提交待办（2026-08-11）

### P11: 收款码等图片也接入图床自动上传 ⚠️ 安全审查

**复杂度**: 小 | **影响**: 🟡 团长效率 | **安全**: ⚠️ 需评审

当前收款码（微信/支付宝二维码）场景不走图床，团长需手动处理图片。接入自动上传可省一步，但 **收款码上传到第三方图床存在资金安全风险**：
- 图床服务商/API 中间人可能替换二维码图片
- 付款方扫码后进入假冒收款页面
- **建议**: 收款码使用 Base64 本地存储或仅上传到 Supabase Storage（受控环境），不上传至第三方图床

**需安全评审后再实施。**

### P12: "?!猪猪?!"等额外功能独立开关

**复杂度**: 小 | **影响**: 🟢 用户体验

将彩蛋/实验性功能（表情包、随机口号等）集中管理，在管理面板增设独立开关区域，默认关闭。

### P13: 导入数据模板支持闲鱼格式

**复杂度**: 中 | **影响**: 🟡 数据迁移

新增 CSV 导入模板解析器，支持闲鱼（闲鱼二手交易平台）导出格式的列名映射：商品标题、价格、运费、状态等字段自动识别并映射到系统字段。

### P14: 🔴 免费图床不稳定的问题

**复杂度**: 小 | **影响**: 🔴 全平台阻塞

截图中的 `cdn1.vip` 默认图床 SSL 证书已过期，`ERR_CERT_DATE_INVALID` 导致所有上传失败。当前只能靠团长自行寻找并配置替代图床。

**方案**:
1. **短期**: 默认图床地址更新为当前可用的免费图床（如 SM.MS），并提供配置指引
2. **中期**: 添加图床连通性检测（页面加载时 `HEAD` 请求探测，不可用时弹黄条警告）
3. **长期**: 考虑用 Supabase Storage 替代第三方图床（属于自有基础设施，无第三方依赖风险）

### P15: 自定义背景功能

**复杂度**: 小 | **影响**: 🟢 个性化

允许管理员上传自定义背景图片（或选择预设主题背景），存储到云端配置，全端生效。可作为 P5（二次元风格美化）的前置子项。

### P16: 图床 API 配置 UI 位置调整

**复杂度**: 小 | **影响**: 🟡 用户体验

当前图床配置 UI 嵌套在 `renderCloudSettings()` 的各囤货地邮费与收款码配置中，外观上像是邮费/收款码的子项。实际图床是全局配置，应独立为一个配置区块，视觉上与邮费/收款码平级。

## 暂缓：旧图片自动迁移

不对历史图片全量迁移。策略：新上传走新图床 + 旧图片保持原 URL + 提供单张"迁移此图片"按钮。原因：旧图床不可达风险、CORS 限制、迁移耗时长、回滚困难。
